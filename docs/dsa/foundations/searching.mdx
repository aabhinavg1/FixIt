# Searching

Searching means finding a target inside a collection.

## In one line

Searching asks, "Is the thing here, and where is it?"

## Real-life example

You look for one name in your phone contacts.

If the list is short, you can scan it.
If the list is long, you want a better way.

## Study use case

Searching happens when you:

- look for a chapter in notes,
- check whether a topic is done,
- or find one practice question from a long list.

## Why it matters

A beginner should learn that searching is not one fixed method.

Sometimes a simple scan is enough.
Sometimes you need the data arranged differently so search becomes faster.

## What beginners should remember

- Searching is about finding a target.
- The data shape matters.
- A repeated search is usually worth optimizing.

## Common mistake

Do not assume every search is fast by default.

If you have to inspect one item at a time, the cost grows with the size of the list.

## Try this

Imagine you need to find a topic name in:

- a tiny checklist,
- a medium notes file,
- and a huge study archive.

Which one would you scan first, and which one would need a better structure?
