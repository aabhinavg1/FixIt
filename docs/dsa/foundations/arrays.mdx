# Arrays

An array stores items one after another in order.

## In one line

An array is a row of values.

## Real-life example

Think of seats in a cinema row.

Seat 1, seat 2, seat 3, and so on are in a fixed order.

If you know the seat number, you can go directly to it.

## Study use case

An array can hold:

- chapter numbers,
- quiz scores,
- days of the week,
- or a checklist of topics.

## Why it matters

Arrays are one of the first structures beginners learn because they are easy to picture.

They are useful when:

- order matters,
- the data is mostly a list,
- and you want quick access by position.

## What beginners should remember

- Arrays keep order.
- Arrays are good for simple lists.
- Arrays are often the first step before more complex structures.

## Common mistake

Do not use an array for everything.

If your task is about relationships or hierarchy, a different structure may fit better.

## Try this

List five things in a row:

- homework tasks,
- chapters,
- movies,
- contact names,
- or practice topics.

Then ask what would change if you needed to insert in the middle or search by name.
