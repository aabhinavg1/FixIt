## Recommended order

1. [What Is DSA?](/docs/dsa/foundations/what-is-dsa/) - learn the subject in one plain sentence.
2. [Data](/docs/dsa/foundations/data/) - understand what information a program stores.
3. [Algorithm](/docs/dsa/foundations/algorithm/) - learn how step-by-step problem solving works.
4. [Arrays](/docs/dsa/foundations/arrays/) - see ordered storage in the simplest form.
5. [Strings](/docs/dsa/foundations/strings/) - understand text as a sequence of characters.
6. [Searching](/docs/dsa/foundations/searching/) - find a target inside a collection.
7. [Sorting](/docs/dsa/foundations/sorting/) - arrange data so later work gets easier.
8. [Stack and Queue](/docs/dsa/foundations/stack-and-queue/) - learn the two basic waiting-order models.
9. [Connected Data](/docs/dsa/foundations/connected-data/) - explore linked lists, trees, and graphs.
10. [Hash Maps and Complexity](/docs/dsa/foundations/hash-map-and-complexity/) - combine fast lookup with growth thinking.

## Why this section is split

Beginners learn faster when each idea stays small enough to explain clearly.

Each deep-dive page keeps one concept focused, uses a real-life example, and ends with a study use case so the idea is easy to remember.
