# Strings

A string is a sequence of characters.

## In one line

A string is text stored as ordered characters.

## Real-life example

Your chat messages, file names, email addresses, and notes are all strings.

## Study use case

Strings show up when you:

- read a problem statement,
- save a chapter title,
- search notes for a keyword,
- or check a typed answer.

## Why it matters

Strings look simple, but many beginner problems use them.

They teach you how to handle:

- letters,
- spaces,
- punctuation,
- and patterns in text.

## What beginners should remember

- Strings are ordered text.
- A string is not just a word; it can be a full sentence or a code.
- Many search and parsing problems start with strings.

## Common mistake

Do not assume text is always easy just because you can read it.

A computer must still decide how to compare, split, store, or search the characters.

## Try this

Take a sentence from your notes and ask:

- what is the first character,
- what is the last character,
- and how would you find one keyword inside it?
