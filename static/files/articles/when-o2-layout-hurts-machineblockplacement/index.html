Do they agree?

Yes on direction: -O2 raises branch-mispredict pressure vs -O1; -O2 -mllvm -disable-block-placement moves back toward -O1. Absolute instruction totals differ across runners; do not merge them.

  • perf: O2 vs O1 time +10.7%, branch misses ~2.63×
  • csperf: O2 vs O1 time +7.7%, branch misses ~2.62×
  • AMD uProf CLI (strtoll hotspot): O2 vs O1 branch-mispred PTI ~4.55×; O2np ≈ O1
