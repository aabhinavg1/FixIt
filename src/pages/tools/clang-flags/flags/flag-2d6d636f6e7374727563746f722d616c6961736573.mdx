## What this flag actually does

Enable emitting complete constructors and destructors as aliases when possible



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.

## When to use it

- You are targeting Target-dependent compilation options and want this flag behavior applied to the whole compilation.
- You are driving the frontend directly or forwarding the option with `-Xclang`, since the driver does not expose it.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Target-dependent compilation options.
- You expect the option to work as a regular driver flag — it requires `-Xclang` forwarding or a direct `clang -cc1` invocation.

## Usage example

```bash
clang++ -Xclang -mconstructor-aliases -fsyntax-only main.cpp
```
