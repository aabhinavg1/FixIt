## What this flag actually does

Enable aliasing mode in HWAddressSanitizer



It can be negated with -fno-sanitize-hwaddress-experimental-aliasing.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-hwaddress-experimental-aliasing main.cpp -o app
```
