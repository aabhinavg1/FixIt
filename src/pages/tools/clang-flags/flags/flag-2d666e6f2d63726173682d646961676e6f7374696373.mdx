## What this flag actually does

Disable auto-generation of preprocessed source files and a script for reproduction during a clang crash



It can be negated with -fcrash-diagnostics.



It is an alias for -gen-reproducer=.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fno-crash-diagnostics -c main.cpp
```
