## What this flag actually does

OpenCL only. Specify that single precision floating-point divide and sqrt used in the program source are correctly rounded.

## When to use it

- You are targeting OpenCL options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting OpenCL options.

## Usage example

```bash
clang++ -cl-fp32-correctly-rounded-divide-sqrt main.cpp -o app
```
