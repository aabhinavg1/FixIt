## What this flag actually does

Disable sanitizer statistics gathering.



It can be negated with -fsanitize-stats.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

