## What this flag actually does

OpenCL only. Defines that the global work-size be a multiple of the work-group size specified to clEnqueueNDRangeKernel



It is an alias for -foffload-uniform-block.

## When to use it

- You are targeting OpenCL options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting OpenCL options.

## Usage example

```bash
clang++ -cl-uniform-work-group-size main.cpp -o app
```
