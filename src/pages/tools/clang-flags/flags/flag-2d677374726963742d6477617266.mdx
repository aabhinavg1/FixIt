## What this flag actually does

Restrict DWARF features to those defined in the specified version, avoiding features from later versions.

## When to use it

- Debug sessions
- Crash investigation
- When you need symbols or richer debug info

## When not to use it

- Release builds without a debugging need
- When size or startup time matters more than observability

## Usage example

```bash
clang++ -gstrict-dwarf -g -c main.cpp
```
