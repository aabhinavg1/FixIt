## What this flag actually does

Disable use-after-scope detection in AddressSanitizer



It can be negated with -fsanitize-address-use-after-scope.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-address-use-after-scope main.cpp -o app
```
