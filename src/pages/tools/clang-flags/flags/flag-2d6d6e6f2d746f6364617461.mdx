## What this flag actually does

This is the default. TOC data transformation is not applied to any variables. Only variables specified explicitly in -mtocdata= will have the TOC data transformation.

## When to use it

- You are targeting Target-dependent compilation options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Target-dependent compilation options.

## Usage example

```bash
clang++ -mno-tocdata -c main.cpp
```
