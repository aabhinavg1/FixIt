## What this flag actually does

Don't use constructor homing for debug info



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



It can be negated with -fuse-ctor-homing.

## When to use it

- Debug sessions
- Crash investigation
- When you need symbols or richer debug info

## When not to use it

- Release builds without a debugging need
- When size or startup time matters more than observability

## Usage example

```bash
clang++ -Xclang -fno-use-ctor-homing -fsyntax-only main.cpp
```
