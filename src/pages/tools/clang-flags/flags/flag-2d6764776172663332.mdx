## What this flag actually does

Enables DWARF32 format for ELF binaries, if debug information emission is enabled.

## When to use it

- Debug sessions
- Crash investigation
- When you need symbols or richer debug info

## When not to use it

- Release builds without a debugging need
- When size or startup time matters more than observability

## Usage example

```bash
clang++ -gdwarf32 -g -c main.cpp
```

- **Argument form**: Flag (no argument)
- **Accepted by**: ClangOption, CC1Option, CC1AsOption
