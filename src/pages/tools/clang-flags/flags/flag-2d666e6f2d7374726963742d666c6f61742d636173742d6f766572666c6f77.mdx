## What this flag actually does

Relax language rules and try to match the behavior of the target's native float-to-int conversion instructions



It can be negated with -fstrict-float-cast-overflow.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When the option does not affect your current build phase
