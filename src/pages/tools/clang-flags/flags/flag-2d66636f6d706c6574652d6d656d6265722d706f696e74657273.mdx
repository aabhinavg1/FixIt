## What this flag actually does

Require member pointer base types to be complete if they would be significant under the Microsoft ABI



It can be negated with -fno-complete-member-pointers.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fcomplete-member-pointers -c main.cpp
```
