## What this flag actually does

Emit complete descriptions of template parameters in forward declarations



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.

## When to use it

- Debug sessions
- Crash investigation
- When you need symbols or richer debug info

## When not to use it

- Release builds without a debugging need
- When size or startup time matters more than observability

## Usage example

```bash
clang++ -Xclang -debug-forward-template-params -fsyntax-only main.cpp
```

- **Argument form**: Flag (no argument)
- **Accepted by**: CC1Option
- **Stage**: cc1 (frontend), category `Debugging`
