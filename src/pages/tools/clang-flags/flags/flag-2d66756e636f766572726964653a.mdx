## What this flag actually does

Mark &lt;function> as being replaceable by the Windows kernel loader



This option expects an argument.

## When to use it

- You are targeting &lt;clang-cl compile-only options> and want this joined behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting &lt;clang-cl compile-only options>.

## Usage example

```bash
clang++ -funcoverride:=<arg> main.cpp -o app
```
