## What this flag actually does

Emit PCs for code covered with binary analysis sanitizers



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -Xclang -fexperimental-sanitize-metadata=covered -fsyntax-only main.cpp
```
