## What this flag actually does

Compile SYCL code for host only. Has no effect on non-SYCL compilations



It is an alias for --offload-host-only.

## When to use it

- You are targeting SYCL options and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting SYCL options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -fsycl-host-only main.cpp -o app
```
