## What this flag actually does

Place all main program variables in static memory (otherwise scalars may be placed on the stack)



It can be negated with -fno-save-main-program.

## When to use it

- You have a concrete need for the behavior this Other option enables and have verified it applies to your build.

## When not to use it

- The behavior enabled by this option does not apply to the code or target you are building.

## Usage example

```bash
clang++ -fsave-main-program main.cpp -o app
```
