## What this flag actually does

Produce a faster access sequence for local-exec TLS variables where the offset from the TLS base is encoded as an immediate operand (AIX 64-bit only). This access sequence is not used for variables larger than 32KB.

## When to use it

- You are targeting PowerPC and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting PowerPC.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -maix-small-local-exec-tls main.cpp -o app
```

- **Argument form**: Flag (no argument)
