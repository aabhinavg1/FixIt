## What this flag actually does

Flags that will be passed onto the ``gfortran`` compiler when Clang is given a Fortran input.



This option expects an argument.



It is an alias for -module-dir.

## When to use it

- You are targeting Fortran compilation options and want this joinedorseparate behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this joinedorseparate is accepted only when targeting Fortran compilation options.

## Usage example

```bash
clang++ -J=<arg> main.cpp -o app
```
