## What this flag actually does

Enable detection of uninitialized parameters and return values



It can be negated with -fno-sanitize-memory-param-retval.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-memory-param-retval main.cpp -o app
```
