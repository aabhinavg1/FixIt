## What this flag actually does

Select between "command" and "reactor" executable models. Commands have a main-function which scopes the lifetime of the program. Reactors are activated and remain active until explicitly terminated.



This option expects an argument.

## When to use it

- You are targeting WebAssembly Driver and want this joined behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting WebAssembly Driver.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -mexec-model= main.cpp -o app
```
