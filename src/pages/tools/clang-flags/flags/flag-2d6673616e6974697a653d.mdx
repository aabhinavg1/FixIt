## What this flag actually does

Turn on runtime checks for various forms of undefined or suspicious behavior. See user manual for available checks



It can be negated with -fno-sanitize=.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize= main.cpp -o app
```
