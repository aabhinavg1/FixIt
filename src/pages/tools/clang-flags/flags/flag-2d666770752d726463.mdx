## What this flag actually does

Generate relocatable device code, also known as separate compilation mode



It can be negated with -fno-gpu-rdc.

## When to use it

- You are targeting Common Offloading options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Common Offloading options.

## Usage example

```bash
clang++ -fgpu-rdc main.cpp -o app
```

- **Argument form**: Flag (no argument)

- **Stage**: cc1 (frontend), category `Common Offloading`
