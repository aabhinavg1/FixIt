## What this flag actually does

Forward options to the linker

## When to use it

- You are targeting &lt;clang-cl options> and want this remaining args joined behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this remaining args joined is accepted only when targeting &lt;clang-cl options>.

## Usage example

```bash
clang++ -link main.cpp -o app
```
