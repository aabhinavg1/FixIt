## What this flag actually does

Exclude sanitization for the top hottest code responsible for the given fraction of PGO counters (0.0 [default] = skip none; 1.0 = skip all). Argument format: &lt;sanitizer1>=&lt;value1>,&lt;sanitizer2>=&lt;value2>,...

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-skip-hot-cutoff= main.cpp -o app
```

- **Argument form**: COMMAJOINED (no argument)
