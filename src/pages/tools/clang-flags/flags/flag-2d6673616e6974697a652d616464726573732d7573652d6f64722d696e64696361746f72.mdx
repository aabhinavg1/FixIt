## What this flag actually does

Enable ODR indicator globals to avoid false ODR violation reports in partially sanitized programs at the cost of an increase in binary size



It can be negated with -fno-sanitize-address-use-odr-indicator.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-address-use-odr-indicator main.cpp -o app
```
