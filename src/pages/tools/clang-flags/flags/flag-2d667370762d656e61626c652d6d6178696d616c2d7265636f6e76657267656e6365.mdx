## What this flag actually does

Enables the MaximallyReconvergesKHR execution mode for this module. This ensures that control flow reconverges at well-defined merge points as defined by the Vulkan spec.

## When to use it

- You are targeting clang-dxc options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting clang-dxc options.

## Usage example

```bash
clang++ -fspv-enable-maximal-reconvergence main.cpp -o app
```

- **Accepted by**: CC1Option, DXCOption
