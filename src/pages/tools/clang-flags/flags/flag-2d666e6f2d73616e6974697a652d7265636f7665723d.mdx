## What this flag actually does

Disable recovery for specified sanitizers



It can be negated with -fsanitize-recover=.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-recover= main.cpp -o app
```
