## What this flag actually does

OpenCL only. Enable or disable OpenCL extensions/optional features. The argument is a comma-separated sequence of one or more extension names, each prefixed by '+' or '-'.

## When to use it

- You are targeting OpenCL options and want this commajoined behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this commajoined is accepted only when targeting OpenCL options.

## Usage example

```bash
clang++ -cl-ext= main.cpp -o app
```
