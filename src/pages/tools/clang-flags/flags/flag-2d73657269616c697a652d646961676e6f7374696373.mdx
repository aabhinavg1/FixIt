## What this flag actually does

Serialize compiler diagnostics to a file



This option expects an argument.

## When to use it

- CI builds
- When you want stricter diagnostics
- When you need to catch regressions early

## When not to use it

- If you are intentionally suppressing noisy third-party warnings
- When you are not ready to fix all warnings

## Usage example

```bash
clang++ -serialize-diagnostics <arg> -fsyntax-only main.cpp
```
