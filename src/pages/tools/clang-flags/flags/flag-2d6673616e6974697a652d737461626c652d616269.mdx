## What this flag actually does

Stable ABI instrumentation for sanitizer runtime. Default: Conventional



It can be negated with -fno-sanitize-stable-abi.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-stable-abi main.cpp -o app
```
