## What this flag actually does

Align branches within 32-byte boundaries to mitigate the performance impact of the Intel JCC erratum.



It is an alias for -mbranches-within-32B-boundaries.

## When to use it

- You are targeting &lt;clang-cl options> and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting &lt;clang-cl options>.

## Usage example

```bash
clang++ -QIntel-jcc-erratum main.cpp -o app
```
