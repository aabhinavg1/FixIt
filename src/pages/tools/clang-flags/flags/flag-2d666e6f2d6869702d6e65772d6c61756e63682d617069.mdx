## What this flag actually does

Don't use new kernel launching API for HIP



It can be negated with -fhip-new-launch-api.

## When to use it

- You are targeting HIP options and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting HIP options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -fno-hip-new-launch-api main.cpp -o app
```
