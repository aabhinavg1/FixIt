## What this flag actually does

Assume that externally defined data is in the small data if it meets the -G &lt;size> threshold (MIPS)

## When to use it

- Final link steps
- When forwarding flags to the linker
- Build systems that need linker-specific control

## When not to use it

- Pure compilation steps
- When the linker should not see the option

## Usage example

```bash
clang++ -mextern-sdata main.o -o app
```
