## What this flag actually does

Specify that single precision floating-point divide and sqrt used in the program source are correctly rounded (HIP device compilation only)



It can be negated with -fno-hip-fp32-correctly-rounded-divide-sqrt.

## When to use it

- You are targeting HIP options and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting HIP options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -fhip-fp32-correctly-rounded-divide-sqrt main.cpp -o app
```

- **Argument form**: Flag (no argument)

- **Stage**: driver, category `HIP`
- **Negated by**: `-fno-hip-fp32-correctly-rounded-divide-sqrt`
