## What this flag actually does

Flags controlling which warnings, errors, and remarks Clang will generate. See the :doc:`full list of warning and remark flags &lt;DiagnosticsReference>`.



This option expects an argument.

## When to use it

- CI builds
- When you want stricter diagnostics
- When you need to catch regressions early

## When not to use it

- If you are intentionally suppressing noisy third-party warnings
- When you are not ready to fix all warnings

## Usage example

```bash
clang++ --warning-suppression-mappings= -fsyntax-only main.cpp
```
