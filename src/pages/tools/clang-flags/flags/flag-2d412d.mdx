## What this flag actually does

Flags that will be passed onto the ``gfortran`` compiler when Clang is given a Fortran input.

## When to use it

- You are targeting Fortran compilation options and want this joined behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting Fortran compilation options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -A- main.cpp -o app
```

## Key facts

- **Argument form**: Joined (no argument)
- **Accepted by**: ClangOption
- **Stage**: driver, category `Fortran compilation`
- **Defined in**: `clang/include/clang/Driver/Options.td`
