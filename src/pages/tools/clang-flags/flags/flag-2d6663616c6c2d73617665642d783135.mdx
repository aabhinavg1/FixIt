## What this flag actually does

Make the x15 register call-saved (AArch64 only)

## When to use it

- You are targeting AArch64 and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting AArch64.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -fcall-saved-x15 main.cpp -o app
```
