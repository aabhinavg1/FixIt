## What this flag actually does

Enable sanitizer statistics gathering.



It can be negated with -fno-sanitize-stats.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-stats main.cpp -o app
```
