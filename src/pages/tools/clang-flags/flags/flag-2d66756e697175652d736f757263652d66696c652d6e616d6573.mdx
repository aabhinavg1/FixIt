## What this flag actually does

Allow the compiler to assume that each translation unit has a unique source file identifier (see -funique-source-file-identifier) at link time



It can be negated with -fno-unique-source-file-names.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -funique-source-file-names -c main.cpp
```
