## What this flag actually does

An allocatable left-hand side of an intrinsic assignment is assumed to be allocated and match the shape/type of the right-hand side



It can be negated with -frealloc-lhs.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fno-realloc-lhs -c main.cpp
```
