## What this flag actually does

Do not allow compiler to annotate sanitizer instrumentation with extra debug info for the specified sanitizers



It can be negated with -fsanitize-annotate-debug-info=.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-annotate-debug-info= main.cpp -o app
```
