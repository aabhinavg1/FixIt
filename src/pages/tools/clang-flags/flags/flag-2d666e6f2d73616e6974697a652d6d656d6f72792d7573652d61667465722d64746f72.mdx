## What this flag actually does

Disable use-after-destroy detection in MemorySanitizer



It can be negated with -fsanitize-memory-use-after-dtor.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-memory-use-after-dtor main.cpp -o app
```
