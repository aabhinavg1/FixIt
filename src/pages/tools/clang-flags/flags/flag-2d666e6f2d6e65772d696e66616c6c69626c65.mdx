## What this flag actually does

Disable treating throwing global C++ operator new as always returning valid memory (annotates with __attribute__((returns_nonnull)) and throw()). This is detectable in source.



It can be negated with -fnew-infallible.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fno-new-infallible -c main.cpp
```
