## What this flag actually does

Flags that will be passed onto the ``gfortran`` compiler when Clang is given a Fortran input.



It can be negated with -fno-aggressive-function-elimination.

## When to use it

- You are targeting Fortran compilation options and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Fortran compilation options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -faggressive-function-elimination main.cpp -o app
```

- **Argument form**: Flag (no argument)
