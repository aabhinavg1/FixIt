## What this flag actually does

Enable builtin #include directories even when -nostdinc is used before or after -ibuiltininc. Using -nobuiltininc after the option disables it

## When to use it

- Controlling macro expansion
- Dependency generation
- Include path management

## When not to use it

- Late codegen tuning
- When you do not want preprocessing behavior changed

## Usage example

```bash
clang++ -ibuiltininc -E input.cpp
```

- **Argument form**: Flag (no argument)
