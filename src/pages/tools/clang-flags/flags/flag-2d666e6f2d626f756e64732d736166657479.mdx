## What this flag actually does

Public negated name: -fno-bounds-safety. CC1-only; forward with -Xclang -fno-experimental-bounds-safety.



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



It can be negated with -fbounds-safety.



LLVM documents the public name `-fno-bounds-safety`; the cc1 spelling is `-fno-experimental-bounds-safety`.



Preview builds enable the mode with `-Xclang -fexperimental-bounds-safety` (public name `-fbounds-safety` per [BoundsSafety.html](https://clang.llvm.org/docs/BoundsSafety.html)).

## When not to use it
