## What this flag actually does

Follows the AAPCS standard that all volatile bit-field write generates at least one load. (ARM only).

## When to use it

- Final link steps
- When forwarding flags to the linker
- Build systems that need linker-specific control

## When not to use it

- Pure compilation steps
- When the linker should not see the option

## Usage example

```bash
clang++ -faapcs-bitfield-load main.o -o app
```
