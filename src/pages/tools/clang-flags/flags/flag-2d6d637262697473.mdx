## What this flag actually does

Control the CR-bit tracking feature on PowerPC. ``-mcrbits`` (the enablement of CR-bit tracking support) is the default for POWER8 and above, as well as for all other CPUs when optimization is applied (-O2 and above).

## When to use it

- Release builds
- Performance-critical code
- When profiling shows a hot path

## When not to use it

- Debug builds
- When compile time is more important than runtime speed

## Usage example

```bash
clang++ -mcrbits main.cpp -o app
```
