## What this flag actually does

Path to ptxas (used for compiling CUDA code)



This option expects an argument.

## When to use it

- You are targeting CUDA options and want this joined behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting CUDA options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ --ptxas-path= main.cpp -o app
```
