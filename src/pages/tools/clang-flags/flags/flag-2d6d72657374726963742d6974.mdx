## What this flag actually does

Disallow generation of complex IT blocks. It is off by default.

## When to use it

- You are targeting ARM and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting ARM.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -mrestrict-it main.cpp -o app
```
