## What this flag actually does

Don't instrument functions with loops unless they also meet the minimum function size



It can be negated with -fno-xray-ignore-loops.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fxray-ignore-loops -c main.cpp
```
