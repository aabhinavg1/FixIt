## What this flag actually does

Enable using library calls for save and restore

## When to use it

- You are targeting RISC-V and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting RISC-V.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -msave-restore main.cpp -o app
```

- **Argument form**: Flag (no argument)
