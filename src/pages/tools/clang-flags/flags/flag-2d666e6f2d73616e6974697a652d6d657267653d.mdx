## What this flag actually does

Do not allow compiler to merge handlers for specified sanitizers



It can be negated with -fsanitize-merge=.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-merge= main.cpp -o app
```
