## What this flag actually does

Disable sc.q instruction.

## When to use it

- You are targeting LoongArch and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting LoongArch.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -mno-scq main.cpp -o app
```
