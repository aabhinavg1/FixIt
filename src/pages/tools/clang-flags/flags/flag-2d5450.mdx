## What this flag actually does

Treat all source files as C++

## When to use it

- You are targeting &lt;clang-cl compile-only options> and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting &lt;clang-cl compile-only options>.

## Usage example

```bash
clang++ -TP main.cpp -o app
```
