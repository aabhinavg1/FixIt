## What this flag actually does

When -frepack-arrays is in effect, 'whole' enables repacking for arrays that are non-contiguous in any dimension, 'innermost' enables repacking for arrays that are non-contiguous in the innermost dimension (the default)



This option expects an argument.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -frepack-arrays-contiguity= -c main.cpp
```
