## What this flag actually does

Flags controlling the behavior of Clang during compilation. These flags have no effect during actions that do not perform compilation.

## When to use it

- Compilation-only workflows
- Build pipelines that do not link immediately

## When not to use it

- Link-only operations
- When the flag belongs in a later build phase

## Usage example

```bash
clang++ -ansi main.cpp -o app
```
