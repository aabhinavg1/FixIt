## What this flag actually does

Infer block and edge counts. If the profiles have errors or missing blocks caused by sampling, profile inference (profi) can convert basic block counts to branch probabilities to fix them by extended and re-engineered classic MCMF (min-cost max-flow) approach.



It can be negated with -fno-sample-profile-use-profi.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fsample-profile-use-profi -c main.cpp
```
