## What this flag actually does

Don't specify that single precision floating-point divide and sqrt used in the program source are correctly rounded (HIP device compilation only)



It can be negated with -fhip-fp32-correctly-rounded-divide-sqrt.

## When to use it

- You are targeting HIP options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting HIP options.

## Usage example

```bash
clang++ -fno-hip-fp32-correctly-rounded-divide-sqrt main.cpp -o app
```
