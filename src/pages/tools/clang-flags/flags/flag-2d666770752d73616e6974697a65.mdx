## What this flag actually does

Enable sanitizer for supported offloading devices



It can be negated with -fno-gpu-sanitize.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fgpu-sanitize main.cpp -o app
```
