## What this flag actually does

Restore the default behavior of not embedding source text in DWARF debug sections

## When to use it

- Debug sessions
- Crash investigation
- When you need symbols or richer debug info

## When not to use it

- Release builds without a debugging need
- When size or startup time matters more than observability

```bash
clang++ -gno-embed-source -g -c main.cpp
```
