## What this flag actually does

Do not produce relaxation hints for linkers to try optimizing PIC call sequences into direct calls (MIPS only)

## When to use it

- Final link steps
- When forwarding flags to the linker
- Build systems that need linker-specific control

## When not to use it

- Pure compilation steps
- When the linker should not see the option

## Usage example

```bash
clang++ -mno-relax-pic-calls main.o -o app
```
