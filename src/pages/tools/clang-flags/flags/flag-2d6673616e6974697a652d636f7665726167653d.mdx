## What this flag actually does

Specify the type of coverage instrumentation for Sanitizers



It can be negated with -fno-sanitize-coverage=.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-coverage= main.cpp -o app
```
