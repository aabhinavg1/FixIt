## What this flag actually does

Replace all memory allocation / deallocation calls with hipManagedMalloc / hipFree equivalents

## When to use it

- You are targeting HIP options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting HIP options.

## Usage example

```bash
clang++ --hipstdpar-interpose-alloc main.cpp -o app
```
