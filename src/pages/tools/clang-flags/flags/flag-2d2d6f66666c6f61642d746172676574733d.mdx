## What this flag actually does

Specify a list of target architectures to use for offloading.

## When to use it

- You are targeting Common Offloading options and want this commajoined behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this commajoined is accepted only when targeting Common Offloading options.

## Usage example

```bash
clang++ --offload-targets= main.cpp -o app
```

- **Argument form**: COMMAJOINED (no argument)
- **Accepted by**: ClangOption, CC1Option, FlangOption, FC1Option
