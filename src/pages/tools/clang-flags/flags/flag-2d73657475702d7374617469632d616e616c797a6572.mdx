## What this flag actually does

Set up preprocessor for static analyzer (done automatically when static analyzer is run).



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.

## When to use it

- Controlling macro expansion
- Dependency generation
- Include path management

## When not to use it

- Late codegen tuning
- When you do not want preprocessing behavior changed

## Usage example

```bash
clang++ -Xclang -setup-static-analyzer -fsyntax-only main.cpp
```

## Key facts

- **Argument form**: Flag (no argument)
- **Accepted by**: CC1Option
- **Stage**: cc1 (frontend), category `Preprocessor`
- **Defined in**: `clang/include/clang/Driver/Options.td`
