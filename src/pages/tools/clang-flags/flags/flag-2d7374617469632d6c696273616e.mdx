## What this flag actually does

Statically link the sanitizer runtime (Not supported for ASan, TSan or UBSan on darwin)

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -static-libsan main.cpp -o app
```
