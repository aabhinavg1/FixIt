## What this flag actually does

Add -rpath with architecture-specific resource directory to the linker flags. When --hip-link is specified, also add -rpath with HIP runtime library directory to the linker flags



It can be negated with -fno-rtlib-add-rpath.

## When to use it

- Final link steps
- When forwarding flags to the linker
- Build systems that need linker-specific control

## When not to use it

- Pure compilation steps
- When the linker should not see the option

## Usage example

```bash
clang++ -frtlib-add-rpath main.o -o app
```

## Key facts

- **Argument form**: Flag (no argument)
- **Accepted by**: ClangOption, FlangOption
- **Stage**: driver, category `Linker`
- **Negated by**: `-fno-rtlib-add-rpath`
- **Defined in**: `clang/include/clang/Driver/Options.td`
