## What this flag actually does

Enable atomic operations instrumentation in ThreadSanitizer (default)



It can be negated with -fno-sanitize-thread-atomics.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-thread-atomics main.cpp -o app
```
