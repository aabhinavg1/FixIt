## What this flag actually does

Disable extended coverage to custom allocation functions



It can be negated with -fsanitize-alloc-token-extended.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-alloc-token-extended main.cpp -o app
```
