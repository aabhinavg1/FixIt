## What this flag actually does

Do not generate debug info for types in an object file built from this PCH and do not generate them elsewhere



It can be negated with -fpch-debuginfo.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fno-pch-debuginfo -c main.cpp
```
