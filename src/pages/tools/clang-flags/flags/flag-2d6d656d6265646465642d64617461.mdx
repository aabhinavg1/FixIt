## What this flag actually does

Place constants in the .rodata section instead of the .sdata section even if they meet the -G &lt;size> threshold (MIPS)

## When to use it

- Final link steps
- When forwarding flags to the linker
- Build systems that need linker-specific control

## When not to use it

- Pure compilation steps
- When the linker should not see the option

## Usage example

```bash
clang++ -membedded-data main.o -o app
```

- **Argument form**: Flag (no argument)
- **Accepted by**: ClangOption
- **Stage**: driver, category `Linker`
