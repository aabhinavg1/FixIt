## What this flag actually does

Enable trapping for specified sanitizers



It can be negated with -fno-sanitize-trap=.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-trap= main.cpp -o app
```
