## What this flag actually does

Restrict sanitizer coverage instrumentation exclusively to modules and functions that match the provided special case list, except the blocked ones



This option expects an argument.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-coverage-allowlist= main.cpp -o app
```
