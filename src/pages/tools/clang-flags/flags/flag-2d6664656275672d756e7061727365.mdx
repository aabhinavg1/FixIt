## What this flag actually does

Run the parser and the semantic checks. Then unparse the parse-tree and output the generated Fortran source file.

## When to use it

- You are targeting Actions and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Actions.

## Usage example

```bash
clang++ -fdebug-unparse main.cpp -o app
```
