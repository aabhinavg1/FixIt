## What this flag actually does

Enable linker dead stripping of globals in AddressSanitizer



It can be negated with -fno-sanitize-address-globals-dead-stripping.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-address-globals-dead-stripping main.cpp -o app
```
