## What this flag actually does

Set CPU for optimization without affecting instruction set



It is an alias for -mtune=.

## When to use it

- Release builds
- Performance-critical code
- When profiling shows a hot path

## When not to use it

- Debug builds
- When compile time is more important than runtime speed

## Usage example

```bash
clang++ -tune: main.cpp -o app
```
