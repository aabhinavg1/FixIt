## What this flag actually does

Specify the size in bits of an SVE vector register in streaming mode. Defaults to the vector length agnostic value of "scalable". (AArch64 only)



This option expects an argument.

## When to use it

- You are targeting AArch64 and want this joined behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting AArch64.

## Usage example

```bash
clang++ -msve-streaming-vector-bits= main.cpp -o app
```
