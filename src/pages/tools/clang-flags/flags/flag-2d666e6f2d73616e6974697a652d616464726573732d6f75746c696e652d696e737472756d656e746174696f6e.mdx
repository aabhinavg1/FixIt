## What this flag actually does

Use default code inlining logic for the address sanitizer



It can be negated with -fsanitize-address-outline-instrumentation.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-address-outline-instrumentation main.cpp -o app
```
