## What this flag actually does

Allow the optimizer to discretely increase the number of teams. May cause ignore environment variables that set the number of teams to be ignored. The combination of -fopenmp-assume-teams-oversubscription and -fopenmp-assume-threads-oversubscription may allow the conversion of loops into sequential code by ensuring that each team/thread executes at most one iteration.



It can be negated with -fno-openmp-assume-teams-oversubscription.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fopenmp-assume-teams-oversubscription -c main.cpp
```
