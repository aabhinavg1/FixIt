## What this flag actually does

Override validator version for module. Format: &lt;major.minor>;Default: DXIL.dll version or current internal version



This option expects an argument.

## When to use it

- You are targeting clang-dxc options and want this separate behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this separate is accepted only when targeting clang-dxc options.

## Usage example

```bash
clang++ -validator-version <arg> main.cpp -o app
```
