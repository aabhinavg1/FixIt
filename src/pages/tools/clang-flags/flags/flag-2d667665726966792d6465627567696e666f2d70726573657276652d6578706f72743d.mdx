## What this flag actually does

Export debug info (by testing original Debug Info) failures into specified (JSON) file (should be abs path as we use append mode to insert new JSON objects).



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



This option expects an argument.

## When to use it

- Debug sessions
- Crash investigation
- When you need symbols or richer debug info

## When not to use it

- Release builds without a debugging need
- When size or startup time matters more than observability

## Usage example

```bash
clang++ -Xclang -fverify-debuginfo-preserve-export= -fsyntax-only main.cpp
```
