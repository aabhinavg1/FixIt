## What this flag actually does

Reserve the L2 register (SPARC only)

## When to use it

- You are targeting SPARC and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting SPARC.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -ffixed-l2 main.cpp -o app
```
