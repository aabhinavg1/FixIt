## What this flag actually does

OpenCL only. Allow unsafe floating-point optimizations. Also implies -cl-no-signed-zeros and -cl-mad-enable.

## When to use it

- You are targeting OpenCL options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting OpenCL options.

## Usage example

```bash
clang++ -cl-unsafe-math-optimizations main.cpp -o app
```
