## What this flag actually does

MinGW specific. Enable code generation support for automatic dllimport, and enable support for it in the linker. Enabled by default.



It can be negated with -fno-auto-import.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fauto-import -c main.cpp
```
