## What this flag actually does

Enable control flow integrity (CFI) checks for cross-DSO calls.



It can be negated with -fno-sanitize-cfi-cross-dso.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-cfi-cross-dso main.cpp -o app
```
