## What this flag actually does

Disable emitting metadata for binary analysis sanitizers



It can be negated with -fexperimental-sanitize-metadata=.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-experimental-sanitize-metadata= main.cpp -o app
```
