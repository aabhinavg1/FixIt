## What this flag actually does

Enable experimental lifetime safety for C++



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



It can be negated with -fno-experimental-lifetime-safety.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -Xclang -fexperimental-lifetime-safety -fsyntax-only main.cpp
```
