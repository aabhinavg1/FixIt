## What this flag actually does

Specify that floating-point optimizations are not allowed that assume arguments and results are not +-inf.



It can be negated with -fno-honor-infinities.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fhonor-infinities -c main.cpp
```
