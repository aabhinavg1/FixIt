## What this flag actually does

Enable IEEE strict mode (equivalent to -ffp-model=strict)

## When to use it

- You are targeting clang-dxc options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting clang-dxc options.

## Usage example

```bash
clang++ -Gis main.cpp -o app
```
