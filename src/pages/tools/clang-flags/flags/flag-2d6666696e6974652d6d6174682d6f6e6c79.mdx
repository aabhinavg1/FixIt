## What this flag actually does

Allow floating-point optimizations that assume arguments and results are not NaNs or +-inf. This defines the \_\_FINITE\_MATH\_ONLY\_\_ preprocessor macro.



It can be negated with -fno-finite-math-only.

## When to use it

- Release builds
- Performance-critical code
- When profiling shows a hot path

## When not to use it

- Debug builds
- When compile time is more important than runtime speed

## Usage example

```bash
clang++ -ffinite-math-only main.cpp -o app
```

- **Argument form**: Flag (no argument)

- **Stage**: cc1 (frontend), category `Optimization`
- **Negated by**: `-fno-finite-math-only`
