## What this flag actually does

Force validation of user headers when repeatedly loading a module file within single build session



It can be negated with -fno-modules-force-validate-user-headers.

## When to use it

- Final link steps
- When forwarding flags to the linker
- Build systems that need linker-specific control

## When not to use it

- Pure compilation steps
- When the linker should not see the option

## Usage example

```bash
clang++ -fmodules-force-validate-user-headers main.o -o app
```
