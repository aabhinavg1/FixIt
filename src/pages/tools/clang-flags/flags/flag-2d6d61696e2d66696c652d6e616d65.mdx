## What this flag actually does

Main file name to use for debug info and source if missing



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



This option expects an argument.

## When to use it

- Debug sessions
- Crash investigation
- When you need symbols or richer debug info

## When not to use it

- Release builds without a debugging need
- When size or startup time matters more than observability

## Usage example

```bash
clang++ -Xclang -main-file-name <arg> -fsyntax-only main.cpp
```

## Key facts

- **Argument form**: Separate (takes an argument)
- **Accepted by**: CC1Option, CC1AsOption
- **Stage**: cc1 (frontend), category `Debugging`
- **Defined in**: `clang/include/clang/Driver/Options.td`
