## What this flag actually does

Allow compiler to merge handlers for all sanitizers



It can be negated with -fno-sanitize-merge.



It is an alias for -fsanitize-merge=.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-merge main.cpp -o app
```
