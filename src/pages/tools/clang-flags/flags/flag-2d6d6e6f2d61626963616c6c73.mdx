## What this flag actually does

Disable SVR4-style position-independent code (Mips only)

## When to use it

- You are targeting MIPS and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting MIPS.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -mno-abicalls main.cpp -o app
```
