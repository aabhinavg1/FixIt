## What this flag actually does

Reserve the d7 register (M68k only)

## When to use it

- You are targeting M68k and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting M68k.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -ffixed-d7 main.cpp -o app
```
