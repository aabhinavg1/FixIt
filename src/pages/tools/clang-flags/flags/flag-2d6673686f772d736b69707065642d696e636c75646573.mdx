## What this flag actually does

#include files may be "skipped" due to include guard optimization or #pragma once. This flag makes -H show also such includes.

## When to use it

- Controlling macro expansion
- Dependency generation
- Include path management

## When not to use it

- Late codegen tuning
- When you do not want preprocessing behavior changed

## Usage example

```bash
clang++ -fshow-skipped-includes -E input.cpp
```
