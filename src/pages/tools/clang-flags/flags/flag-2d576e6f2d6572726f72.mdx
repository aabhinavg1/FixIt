## What this flag actually does

Keeps warnings as warnings even when -Werror or a -Werror= override is active. Negated form of -Werror.



It can be negated with -Werror.

## When to use it

- CI builds
- When you want stricter diagnostics
- When you need to catch regressions early

## When not to use it

- If you are intentionally suppressing noisy third-party warnings
- When you are not ready to fix all warnings

## Usage example

```bash
clang++ -Wno-error -fsyntax-only main.cpp
```
