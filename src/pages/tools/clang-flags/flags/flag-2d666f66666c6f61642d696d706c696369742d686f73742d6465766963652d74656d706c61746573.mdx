## What this flag actually does

Template functions or specializations without host, device and global attributes have implicit host device attributes (CUDA/HIP only)



It can be negated with -fno-offload-implicit-host-device-templates.

## When to use it

- You are targeting Common Offloading options and want this flag behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Common Offloading options.

## Usage example

```bash
clang++ -foffload-implicit-host-device-templates main.cpp -o app
```

- **Argument form**: Flag (no argument)
