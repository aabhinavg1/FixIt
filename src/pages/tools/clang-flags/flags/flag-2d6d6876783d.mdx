## What this flag actually does

Enable Hexagon Vector eXtensions



This option expects an argument.

## When to use it

- You are targeting Hexagon and want this joined behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting Hexagon.
- You need the same behavior from GCC or another compiler that does not implement this option.
