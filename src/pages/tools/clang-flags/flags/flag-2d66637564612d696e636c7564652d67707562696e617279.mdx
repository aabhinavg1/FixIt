## What this flag actually does

Incorporate CUDA device-side binary into host object file.



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



This option expects an argument.

## When to use it

- Controlling macro expansion
- Dependency generation
- Include path management

## When not to use it

- Late codegen tuning
- When you do not want preprocessing behavior changed

## Usage example

```bash
clang++ -Xclang -fcuda-include-gpubinary <arg> -fsyntax-only main.cpp
```
