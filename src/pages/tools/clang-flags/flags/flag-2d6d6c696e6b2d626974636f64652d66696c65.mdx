## What this flag actually does

Link the given bitcode file before performing optimizations.



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



This option expects an argument.

## When to use it

- Release builds
- Performance-critical code
- When profiling shows a hot path

## When not to use it

- Debug builds
- When compile time is more important than runtime speed

## Usage example

```bash
clang++ -Xclang -mlink-bitcode-file <arg> -fsyntax-only main.cpp
```

## Key facts

- **Argument form**: Separate (takes an argument)
- **Accepted by**: CC1Option, FC1Option
- **Stage**: cc1 (frontend), category `Optimization`
- **Defined in**: `clang/include/clang/Driver/Options.td`
