## What this flag actually does

Specify Visual Studio C runtime library. "static" and "static_dbg" correspond to the cl flags /MT and /MTd which use the multithread, static version. "dll" and "dll_dbg" correspond to the cl flags /MD and /MDd which use the multithread, dll version.



This option expects an argument.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fms-runtime-lib= -c main.cpp
```
