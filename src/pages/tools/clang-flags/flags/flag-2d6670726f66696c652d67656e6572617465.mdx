## What this flag actually does

Generate instrumented code to collect execution counts into default.profraw (overridden by LLVM_PROFILE_FILE env var)



It can be negated with -fno-profile-generate.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -fprofile-generate -c main.cpp
```
