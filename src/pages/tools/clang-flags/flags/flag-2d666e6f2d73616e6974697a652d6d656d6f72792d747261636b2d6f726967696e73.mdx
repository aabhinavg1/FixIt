## What this flag actually does

Disable origins tracking in MemorySanitizer



It can be negated with -fsanitize-memory-track-origins.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-memory-track-origins main.cpp -o app
```
