## What this flag actually does

OpenCL only. Allow denormals to be flushed to zero.

## When to use it

- You are targeting OpenCL options and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting OpenCL options.
- You need the same behavior from GCC or another compiler that does not implement this option.
