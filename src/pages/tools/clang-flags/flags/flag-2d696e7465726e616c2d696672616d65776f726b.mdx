## What this flag actually does

Add directory to the internal system framework search path; these are assumed to not be user-provided and are used to model system and standard frameworks' paths.



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



This option expects an argument.

## When to use it

- You are driving the frontend directly or forwarding the option with `-Xclang`, since the driver does not expose it.

## When not to use it

- You expect the option to work as a regular driver flag — it requires `-Xclang` forwarding or a direct `clang -cc1` invocation.

## Usage example

```bash
clang++ -Xclang -internal-iframework <arg> -fsyntax-only main.cpp
```

- **Argument form**: Separate (takes an argument)
- **Accepted by**: CC1Option
- **Stage**: cc1 (frontend), category `Other`
