## What this flag actually does

Instrument device library for HIP, which is a LLVM bitcode containing __cyg_profile_func_enter and __cyg_profile_func_exit



This option expects an argument.

## When to use it

- You are targeting HIP options and want this joined behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting HIP options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ --gpu-instrument-lib= main.cpp -o app
```

## Key facts

- **Argument form**: Joined (takes an argument)
- **Accepted by**: ClangOption
- **Stage**: driver, category `HIP`
- **Defined in**: `clang/include/clang/Driver/Options.td`
