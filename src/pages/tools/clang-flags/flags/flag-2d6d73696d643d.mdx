## What this flag actually does

Select the SIMD extension(s) to be enabled in LoongArch either 'none', 'lsx', 'lasx'.



This option expects an argument.

## When to use it

- You are targeting LoongArch and want this joined behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting LoongArch.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -msimd= main.cpp -o app
```
