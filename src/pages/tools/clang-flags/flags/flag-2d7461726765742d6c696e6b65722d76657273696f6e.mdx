## What this flag actually does

Target linker version



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



This option expects an argument.

## When to use it

- Final link steps
- When forwarding flags to the linker
- Build systems that need linker-specific control

## When not to use it

- Pure compilation steps
- When the linker should not see the option

## Usage example

```bash
clang++ -Xclang -target-linker-version <arg> -fsyntax-only main.cpp
```

## Key facts

- **Argument form**: Separate (takes an argument)
- **Accepted by**: CC1Option
- **Stage**: cc1 (frontend), category `Linker`
- **Defined in**: `clang/include/clang/Driver/Options.td`
