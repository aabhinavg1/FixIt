## What this flag actually does

Specify the printf lowering scheme (AMDGPU only), allowed values are "hostcall"(printing happens during kernel execution, this scheme relies on hostcalls which require system to support pcie atomics) and "buffered"(printing happens after all kernel threads exit, this uses a printf buffer and does not rely on pcie atomic support)



This option expects an argument.

## When to use it

- You are targeting Target-dependent compilation options and want this joined behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting Target-dependent compilation options.

## Usage example

```bash
clang++ -mprintf-kind= -c main.cpp
```
