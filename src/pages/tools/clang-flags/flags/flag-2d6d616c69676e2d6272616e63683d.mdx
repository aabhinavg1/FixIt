## What this flag actually does

Specify types of branches to align

## When to use it

- You are targeting Target-dependent compilation options and want this commajoined behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this commajoined is accepted only when targeting Target-dependent compilation options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -malign-branch= -c main.cpp
```
