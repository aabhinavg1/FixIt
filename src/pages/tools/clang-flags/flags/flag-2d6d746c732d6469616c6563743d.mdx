## What this flag actually does

Which thread-local storage dialect to use for dynamic accesses of TLS variables



This option expects an argument.

## When to use it

- You are targeting Target-dependent compilation options and want this joined behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting Target-dependent compilation options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -mtls-dialect= -c main.cpp
```
