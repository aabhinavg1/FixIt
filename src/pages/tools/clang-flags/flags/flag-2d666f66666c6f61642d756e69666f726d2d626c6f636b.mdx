## What this flag actually does

Assume that kernels are launched with uniform block sizes (default true for CUDA/HIP and false otherwise)



It can be negated with -fno-offload-uniform-block.

## When to use it

- Code generation tuning
- Frontend lowering experiments
- Target-independent compilation control

## When not to use it

- When you are only editing diagnostics or preprocessing
- When the option does not affect your current build phase

## Usage example

```bash
clang++ -foffload-uniform-block -c main.cpp
```
