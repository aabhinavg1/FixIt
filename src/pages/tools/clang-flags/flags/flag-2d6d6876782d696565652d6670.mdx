## What this flag actually does

Enable Hexagon HVX IEEE floating-point

## When to use it

- You are targeting Hexagon and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Hexagon.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -mhvx-ieee-fp main.cpp -o app
```
