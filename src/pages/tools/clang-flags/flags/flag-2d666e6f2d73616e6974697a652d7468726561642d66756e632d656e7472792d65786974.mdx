## What this flag actually does

Disable function entry/exit instrumentation in ThreadSanitizer



It can be negated with -fsanitize-thread-func-entry-exit.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fno-sanitize-thread-func-entry-exit main.cpp -o app
```
