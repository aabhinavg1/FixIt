## What this flag actually does

Overlay the virtual filesystem described by file over the real file system



This option expects an argument.

## When to use it

- You are targeting &lt;clang i group> and want this joinedorseparate behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this joinedorseparate is accepted only when targeting &lt;clang i group>.
