## What this flag actually does

Make the jump table addresses canonical in the symbol table



It can be negated with -fno-sanitize-cfi-canonical-jump-tables.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable

## Usage example

```bash
clang++ -fsanitize-cfi-canonical-jump-tables main.cpp -o app
```
