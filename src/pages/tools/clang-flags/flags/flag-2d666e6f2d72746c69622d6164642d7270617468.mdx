## What this flag actually does

Do not add -rpath with architecture-specific resource directory to the linker flags. When --hip-link is specified, do not add -rpath with HIP runtime library directory to the linker flags



It can be negated with -frtlib-add-rpath.

## When to use it

- Final link steps
- When forwarding flags to the linker
- Build systems that need linker-specific control

## When not to use it

- Pure compilation steps
- When the linker should not see the option

## Usage example

```bash
clang++ -fno-rtlib-add-rpath main.o -o app
```

- **Argument form**: Flag (no argument)
