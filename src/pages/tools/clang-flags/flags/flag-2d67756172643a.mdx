## What this flag actually does

Enable Control Flow Guard with /guard:cf, or only the table with /guard:cf,nochecks. Enable EH Continuation Guard with /guard:ehcont

## When to use it

- You are targeting &lt;clang-cl options> and want this joined behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting &lt;clang-cl options>.

## Usage example

```bash
clang++ -guard: main.cpp -o app
```
