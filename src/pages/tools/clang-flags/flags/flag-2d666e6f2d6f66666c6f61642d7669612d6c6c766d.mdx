## What this flag actually does

Don't use LLVM/Offload as portable offloading runtime.



It can be negated with -foffload-via-llvm.

## When to use it

- You are targeting Common Offloading options and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Common Offloading options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -fno-offload-via-llvm main.cpp -o app
```

- **Argument form**: Flag (no argument)
