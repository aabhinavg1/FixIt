## What this flag actually does

Emit compiler path and command line into CodeView debug information

## When to use it

- Debug sessions
- Crash investigation
- When you need symbols or richer debug info

## When not to use it

- Release builds without a debugging need
- When size or startup time matters more than observability

## Usage example

```bash
clang++ -gcodeview-command-line -g -c main.cpp
```
