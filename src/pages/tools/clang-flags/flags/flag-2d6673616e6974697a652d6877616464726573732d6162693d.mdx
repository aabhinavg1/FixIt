## What this flag actually does

Select the HWAddressSanitizer ABI to target (interceptor or platform, default interceptor). This option is currently unused.



This option expects an argument.

## When to use it

- Bug hunting
- Test environments
- When validating memory and UB safety

## When not to use it

- Shipping performance-critical binaries
- When runtime overhead is unacceptable
