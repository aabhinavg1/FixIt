## What this flag actually does

Specify a directory where Clang can find 'include' and 'lib&#123;,32,64&#125;/gcc&#123;,-cross&#125;/$triple/$version'. Clang will use the GCC installation with the largest version



This option expects an argument.

## When to use it

- Controlling macro expansion
- Dependency generation
- Include path management

## When not to use it

- Late codegen tuning
- When you do not want preprocessing behavior changed

## Usage example

```bash
clang++ --gcc-toolchain= -E input.cpp
```
