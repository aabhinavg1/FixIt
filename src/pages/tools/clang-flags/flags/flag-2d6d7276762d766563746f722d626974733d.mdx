## What this flag actually does

Specify the size in bits of an RVV vector register. Defaults to the vector length agnostic value of "scalable". Accepts power of 2 values between 64 and 65536. Also accepts "zvl" to use the value implied by -march/-mcpu. The value will be reflected in __riscv_v_fixed_vlen preprocessor define (RISC-V only)



This option expects an argument.

## When to use it

- You are targeting Target-dependent compilation options and want this joined behavior applied to the whole compilation.

## When not to use it

- Your build targets a different architecture — this joined is accepted only when targeting Target-dependent compilation options.

## Usage example

```bash
clang++ -mrvv-vector-bits= -c main.cpp
```
