## What this flag actually does

Allow vector memory accesses to be unaligned (RISC-V only)

## When to use it

- You are targeting Target-dependent compilation options and want this flag behavior applied to the whole compilation.
- You are compiling with Clang (the option is not accepted by other compilers).

## When not to use it

- Your build targets a different architecture — this flag is accepted only when targeting Target-dependent compilation options.
- You need the same behavior from GCC or another compiler that does not implement this option.

## Usage example

```bash
clang++ -mno-vector-strict-align -c main.cpp
```
