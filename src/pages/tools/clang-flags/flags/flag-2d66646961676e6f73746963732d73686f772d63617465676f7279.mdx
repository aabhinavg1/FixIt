## What this flag actually does

Print diagnostic category



This is a `-cc1` (internal frontend) option. The Clang driver does not accept it directly, so it must be forwarded with `-Xclang`.



This option expects an argument.

## When to use it

- CI builds
- When you want stricter diagnostics
- When you need to catch regressions early

## When not to use it

- If you are intentionally suppressing noisy third-party warnings
- When you are not ready to fix all warnings

## Usage example

```bash
clang++ -Xclang -fdiagnostics-show-category <arg> -fsyntax-only main.cpp
```
